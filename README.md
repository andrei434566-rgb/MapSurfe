# MapSurfe — Палеоатлас

Локальное приложение Windows с вращающимся глобусом древней Земли.

## Работа на другом компьютере

1. Клонируйте этот репозиторий, чтобы редактировать исходный код и сохранять изменения в Git.
2. В разделе **Releases** скачайте `MapSurfe-source.zip` — полный переносимый проект с картами, локальными данными, исходниками и уведомлениями о лицензиях.
3. Распакуйте архив и следуйте `README.md` внутри для запуска проекта.

Архив не включает локальное состояние приложения, кэш Python и сборочные артефакты из `.build_release_paleoatlas`.
