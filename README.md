# MapSurfe — Палеоатлас

Windows-приложение с вращающимся палеоглобусом (PySide6 + OpenGL), временной шкалой,
палеогеографическими реконструкциями GPlates/PALEOMAP и импортом геологических полигонов.

## Быстрый запуск на Windows

Потребуется **Git**, **Python 3.11 x64** (также поддерживаются 3.10–3.13) и доступ в интернет
для первой установки. Откройте **PowerShell**:

    git clone https://github.com/andrei434566-rgb/MapSurfe.git
    cd MapSurfe
    .\ЗАПУСК.cmd

Или без клонирования: **Code → Download ZIP**, распаковать, дважды нажать
**ЗАПУСК.cmd** / **Запустить Палеоатлас.cmd**.

При первом запуске установщик:

1. Создаёт локальное окружение .venv и ставит библиотеки из requirements.txt.
2. Проверяет наличие данных model/, paleoatlas_rasters/, paleodem_*.zip, cities500.zip.
3. Если их нет, скачивает **MapSurfe-source.zip (около 1,13 ГБ)** из
   [релиза v1.0.0](https://github.com/andrei434566-rgb/MapSurfe/releases/tag/v1.0.0),
   проверяет официальную контрольную сумму SHA-256 и извлекает **только данные**.
4. Запускает окно Палеоатласа.

**Личные файлы и исходники из архива не перезаписываются.** Если доступ к GitHub
для больших файлов ограничен, скачайте MapSurfe-source.zip вручную в папку
проекта или в «Загрузки» и снова запустите .cmd.

Можно также выполнить в PowerShell:

    powershell -NoProfile -ExecutionPolicy Bypass -File .\setup_windows.ps1

Только установить и проверить данные без открытия окна:

    powershell -NoProfile -ExecutionPolicy Bypass -File .\setup_windows.ps1 -SkipLaunch

Для повторных запусков используйте тот же .cmd. Для обновления из GitHub:

    git pull
    .\ЗАПУСК.cmd

## CPS-3 и координаты

В разделе **Полигоны** выберите **Добавить слой**. Для CPS-3 ASCII XY программа
запросит исходную систему координат (EPSG/WKT) и порядок осей. Импортёр сам
пересчитает контуры в WGS84 для глобуса. Для экспорта в другую проекцию
используйте кнопку **Конвертировать CPS-3 в другую СК**.

Пример преобразования в консоли (СК-42, шестиградусная зона 13 — *только пример*):

    .\.venv\Scripts\python.exe cps3_convert.py in.cps out_gk.cps --from-crs EPSG:4326 --to-crs EPSG:28413

Если исходный файл содержит координаты **X (север), Y (восток)**, нужно указать
параметр --from-order yx, а не оставлять порядок XY. Номер зоны и геодезическую основу
надо брать из документации к проекту, а не угадывать по значениям координат.

Обрабатываются CPS-3 ASCII XY-полигоны (пометки ->Имя). **Сетки CPS-3/ZMAP
не являются полигонами** и пока не поддерживаются этим импортёром.

## Проблемы запуска

- Проверьте, что установлен **Python x64** и доступна команда py -3.11.
- Потребуется достаточно места для архива ~1,13 ГБ, распаковки карт и окружения
  Python (желательно 4–6 ГБ свободного места).
- Нужна поддержка OpenGL 3.3 видеодрайвером.
- При исключении приложение сохраняет paleoatlas-qt-error.log.
- Установщик покажет ошибку и не будет запускать неполное приложение без карт.
- Лицензии наборов данных находятся в paleoatlas-license.txt,
  paleodem-license.txt, geonames-license.txt.
