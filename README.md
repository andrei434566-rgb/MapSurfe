# MapSurfe — Палеоатлас

Локальное приложение Windows с вращающимся глобусом древней Земли.

## Скачать готовое приложение

**[Скачать MapSurfe.exe для Windows x64](https://github.com/andrei434566-rgb/MapSurfe/releases/latest/download/MapSurfe.exe)**

Сохраните файл и откройте двойным щелчком. Python, установка библиотек, отдельные архивы и скачивание карт не требуются: карты 0–750 млн лет, модель плит и справочник городов встроены в EXE. Приложение работает офлайн.

При первом открытии подождите автоматической подготовки встроенных компонентов. Настройки сохраняются в `%LOCALAPPDATA%\MapSurfe`. Требуется Windows 10/11 x64 и видеодрайвер с OpenGL 3.3.

## Что можно исследовать

- Перемещаться по палеогеографической шкале от современной Земли до 750 млн лет назад.
- Перейти к ключевым эпохам: Родиния, Гондвана, сборка Пангеи и движение Индии.
- Сравнивать перемещение городов и ориентиров, показывать траектории и загружать собственные лицензионные полигоны.
- Ориентироваться по источнику карты, периоду и оговоркам о точности реконструкции.

## Детализация карты

- Предпочтительный источник — [PALEOMAP PaleoDEM 2024](https://doi.org/10.5281/zenodo.10659112): числовые сетки высот и глубин с шагом 0,1° на всём диапазоне 0–750 млн лет. Атласная палитра сочетает глубокий синий океан, бирюзовый шельф, естественные зелёные низменности, охру и светлые каменные оттенки гор. Матовая светотень подчёркивает рельеф; цвет не обозначает реконструкцию растительности или климата.
- Опубликованные карты идут через 5 млн лет для 0–540 млн лет; древние опорные даты — 600, 630, 690 и 750 млн лет. На опорных датах показывается исходная числовая сетка. Между ними каждый шаг в 1 млн лет меняет расчётную карту: на GPU интерполируются высоты и глубины, после чего единая поверхность окрашивается и получает светотень. Цветные снимки не накладываются друг на друга; граница суши определяется по нулевой высоте полученной поверхности.
- Возраст показанной карты и опорные даты расчёта подписаны под глобусом. Промежуточная карта — визуальная интерполяция, а не самостоятельная опубликованная научная реконструкция. Она не моделирует отдельно движение каждой плиты, эрозию или изменение уровня моря. При больших промежутках между древними опорными датами форма суши может изменяться за счёт появления и исчезновения участков. Положения городов и полигонов рассчитываются по модели плит для возраста на шкале времени.
- Шаг 0,1° (около 11 км у экватора) описывает сетку изображения. Положение берегов, высоты и конфигурации материков в докембрии остаются значительно менее определёнными. Исходная геологическая точность реконструкций различается между эпохами.
- Если архив 2024 года отсутствует, приложение использует PaleoDEM 2018 до 540 млн лет и иллюстрации PALEOMAP 2016 для более древних дат. Активный источник и опорные карты указаны под глобусом.
- Числовые высоты поступают на GPU без JPEG-сжатия; подготовленные цветные снимки сохраняются в PNG без потерь. Фильтрация глобуса учитывает наклон поверхности и шов долготы. Регулятор **«Чёткость» (0–200%)** усиливает существующий рельеф и местный контраст, сохраняя палитру и положение берега; настройка сохраняется между запусками. Удерживайте **«Сравнить»**, чтобы временно увидеть изображение при 0%. При сильном увеличении детализация ограничена исходной сеткой.
- Для карт старше 540 млн лет ступени квантования смягчаются только в градиентах светотени. Сами высоты, по которым вычисляется берег и выбирается цвет, дополнительно не сглаживаются.

## Установка новой подложки

В каталоге проекта выполните команды Python из своего окружения:

```powershell
python fetch_paleodem_2024.py
python build_visual_cache.py
```

Первая команда загружает и проверяет архив `paleodem_2024.zip` и совместимую модель плит v19o. Вторая необязательно готовит цветной PNG-кэш опорных снимков; глобус рассчитывается непосредственно из числовых высот и не требует предварительной подготовки этого кэша. При наличии нового архива приложение выбирает его и соответствующую модель автоматически. Атрибуция и описание изменений: `paleodem2024-license.txt` и `model/SOURCE.md`.

## Работа на другом компьютере

Для обычного использования скачайте готовый `MapSurfe.exe` по ссылке выше. Для редактирования и сборки нужны Python 3.11 x64 и исходники репозитория:

```powershell
git clone https://github.com/andrei434566-rgb/MapSurfe.git
cd MapSurfe
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe fetch_paleodem_2024.py
.\.venv\Scripts\python.exe fetch_city_catalog.py
.\.venv\Scripts\python.exe paleoatlas_qt.pyw
```

Для пересборки автономного приложения установите зависимости сборки и выполните `build_windows.py`. Результат — один EXE в соседнем каталоге `MapSurfe-release`:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-windows-lock.txt -r requirements-build.txt
.\.venv\Scripts\python.exe build_windows.py
```

Сценарий сборки включает только необходимые геоданные и библиотеки, без пользовательской сессии, импортированных участков и локальных кэшей. Старый `MapSurfe-source.zip` остаётся в предыдущем релизе для совместимости прежнего установщика.

## CPS-3 и координаты

В разделе **Полигоны** можно загрузить CPS-3 ASCII XY, GeoJSON, KML и Shapefile ZIP. Для CPS-3 укажите исходную систему координат (EPSG/WKT) и порядок осей. Программа пересчитает контуры в WGS84; кнопка **«Конвертировать CPS-3 в другую СК»** позволяет экспортировать их в другую проекцию. Подробности: [docs/cps3-and-palette.md](docs/cps3-and-palette.md).
