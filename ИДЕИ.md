# Куда развивать Палеоатлас

## Основа научной версии

1. Добавить вторую палеогеографическую серию для эпох древнее 750 млн лет. Нынешний **PALEOMAP PaleoAtlas** содержит 90 опорных карт от 0 до 750 млн лет; более древнее море нельзя восстановить простым переносом нынешних берегов.
2. Для лицензионных участков добавить ручную правку plate ID и историю привязки. Сейчас плита выбирается автоматически по центру; большой участок может пересекать несколько плит — его необходимо разделять.
3. Вводить срок существования каждого именованного объекта. Таймыр как нынешний ориентир можно отслеживать глубже во времени, но подпись «полуостров Таймыр» не должна автоматически означать, что полуостров уже существовал.
4. Добавить преобразование координат через PROJ для российских кадастровых/геологоразведочных систем координат. Отображать определённый CRS и результат преобразования до импорта.

## Самые сильные функции интерфейса

- **Два глобуса рядом:** одна точка/участок на двух возрастах, синхронное вращение и масштаб.
- **След во времени:** клик по городу или участку строит линию движения и график палеошироты, скорости и расстояния до другого объекта.
- **Слои геологии:** границы плит, зоны субдукции, горообразование, древние моря, климатические пояса, уровень моря, оледенения, крупные вымирания. Каждый слой с источником и покрытием по времени.
- **История участка:** карточка лицензионного полигона с современной площадью, атрибутами лицензии и реконструкцией центра/контура с оговоркой о точности.
- **Сюжеты:** сохранённые маршруты по эпохам — например «как путешествовал Таймыр», «сборка Пангеи», «движение Индии к Евразии».
- **Экспорт:** короткое видео/GIF, карта на выбранный возраст и PDF-отчёт с моделью, источниками, годом лицензии, координатной системой и предупреждениями о неопределённости.
- **Закладки и проекты:** сохранение выбранных слоёв, городов, подписей, ракурса и набора сравнений.

## Данные, которые нужны для следующего этапа

- Один реальный файл полигонов лицензий и его система координат.
- Региональные карты Западной Сибири с геологическими интервалами и береговыми линиями для детальной проверки областей ЛУ; глобальный атлас обобщает локальные данные.
