MapSurfe dependency licenses

DEPENDENCIES.json records exact package versions and upstream metadata.
Each package directory preserves its installed notices and METADATA.
The upstream/ directory contains additional upstream license texts,
including the Qt/PySide licensing alternatives and PyOpenGL notices.
pygplates is GPL version 2 only; its complete COPYING is preserved.
PyInstaller is a build tool with a bootloader distribution exception.
Dataset attribution is in the root *license.txt files and model/SOURCE.md.
